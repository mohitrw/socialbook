# Social Book — Facebook UI Clone

A front-end social media website inspired by Facebook, built using HTML, CSS, and JavaScript. Social Book features a home page and a profile page, with light and dark mode support.

This project focuses on creating a clean, responsive user interface while practicing front-end development.

## ✨ Features

* **Home Page** — A social media-inspired interface with a familiar layout.
* **Profile Page** — A dedicated user profile page.
* **Light & Dark Mode** — Switch between light and dark themes.
* **Page Navigation** — Navigate between the home page and profile page.
* **Clean UI** — A modern interface inspired by Facebook.
* **Interactive Elements** — JavaScript-powered interface interactions.

## 🛠️ Built With

* **HTML5** — Website structure and content.
* **CSS3** — Styling, layout, and themes.
* **JavaScript** — Interactive elements and page functionality.

No frameworks or external UI libraries were used.

## 🚀 How to Run Locally

You can run this project locally in just a few steps.

1. Clone the repository:

   ```bash
   git clone YOUR-REPOSITORY-URL
   ```

2. Open the project folder:

   ```bash
   cd social-book
   ```

3. Open `index.html` in your browser.

Alternatively, use the **Live Server** extension in Visual Studio Code for a smoother development experience.

## 📚 What I Learned

Social Book was created as part of my front-end development learning journey.

While following a YouTube tutorial for guidance, I wrote the code myself and worked on implementing the interface and its interactions.

Through this project, I practiced:

* Structuring web pages with HTML5.
* Styling layouts and components with CSS3.
* Using JavaScript to add interactivity.
* Implementing light and dark mode.
* Connecting multiple pages through navigation.
* Translating a visual reference into a working website.

This project helped me strengthen my understanding of front-end fundamentals and gain more confidence in building websites independently.
